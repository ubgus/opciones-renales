# Opciones renales / Renal options

Guía bilingüe (ES/EN) para pacientes sobre terapias de reemplazo renal:
hemodiálisis, diálisis peritoneal, trasplante y cuidado conservador.
Incluye diagramas SVG animados, ilustraciones interactivas y un simulador
educativo de dosis de diálisis.

Bilingual (EN/ES) patient guide to renal replacement therapies:
hemodialysis, peritoneal dialysis, transplant and conservative care.
Includes animated SVG diagrams, interactive illustrations and an
educational dialysis-dose simulator.

**Educational content only — not medical advice / Contenido educativo — no es consejo médico.**

Live / En línea: https://ubgus.github.io/opciones-renales/
